# The canonical step list

| Step | Reads (un-lowered IR fact) | Lowers to | IR design |
|---|---|---|---|
| `CollapseAliases` | `TypePlan.Alias`; the decorator chain's `Docs`, `Deprecation`, `Examples` | no declaration for an aliased type; each reference to it lowered as one to its `Alias`, its annotations folded onto the carrier ([decorators](decorators.md)) | [models](../../ir/models.md); [annotations](../../ir/annotations.md#what-a-reference-carries-down) |
| `ResolveScalarChains` | `plan.ScalarChain` (the `Base` chain walked once, constraints merged), `Ctx.Types` | a declaration over the root ([scalars](scalars.md)), the root typed by the type table ([type table](../contract/type-table.md)), + merged constraints; nil-base → the opaque-scalar strategy | [scalars](../../ir/scalars.md) |
| `LowerContainers` | `List/MapT/Tuple` nodes (with IDs) | list, map and positional forms, a positional form's members past `MinItems` optional and a `Rest` trailing; a nil `MapT.Key` is a string key, and a non-string key → custom-key map or diagnostic | [containers](../../ir/containers.md) |
| `LowerLiterals` | `Literal{Value}` | typed constant / single-value type (incl. `symbol`) | [containers](../../ir/containers.md) |
| `LowerModels` | `TypePlan.Flattened`, `Required`, `Undeclared`, `Unflattened`, `Composed`, `Base`/`Implements`/`Mixins`, `AdditionalProps`, `Additional`, `Positional` | a declaration over the flattened properties, an `Undeclared` member a required field typed as the catch-all types it, the catch-all holding the undeclared members, unknown members rejected on `closed`, a union the model narrows lowered as that union ([inheritance](models.md#inheritance)) and any other `Unflattened` conjunct lowered or degraded with a code | [models](../../ir/models.md) |
| `ProjectVisibilityShapes` | `plan.ModelShape` per shape, a variant composed over a union a model narrows taking its `TypePlan.Composed` entry's ([inheritance](models.md#inheritance)) | one declaration per `ModelShape.Name`, such as `User` / `UserCreate` / `UserUpdatePatch` ([TypePlan](../plan/types.md#the-declaration-a-shape-takes)), and one for each type holding a projected one ([TypePlan](../plan/types.md#a-shape-reaches-what-it-holds)) | [properties](../../ir/properties.md#visibility) |
| `LowerOptionality` | `TypePlan.Required` (a member's wire presence, [TypePlan](../plan/types.md), a variant composed over a union a model narrows reading its `TypePlan.Composed` entry's) ⊥ `TypeRef.Nullable`, a reference to an untagged union with a variant admitting `null` counting as nullable ([unions](unions.md#a-null-a-variant-admits)) ⊥ `Property.Presence`; `Facts.Component` | the four+ states in the target's forms; a reference on a cycle the target holds by value broken as its type system requires ([recursive references](models.md#recursive-references)) | [properties](../../ir/properties.md); INV8 |
| `LowerConstraints` | `Constraints` on properties/scalars/lists/maps | field-level validation metadata + a refine-built validation method structure | [constraints](../../ir/constraints.md) |
| `LowerUnions` | `Union{Variants, Exclusive, WireTagged, Discriminator}`, the union a model narrows with its variants composed ([inheritance](models.md#inheritance)), a polymorphic base's `Discriminator` or `Abstract` with `Facts.Subtypes`, `TypePlan.Union`, `TypePlan.Open`, `TypePlan.Inclusive`, `TypePlan.Strict` and each shape's `ModelShape.Inclusive` | the target's closed sum, one member per variant or subtype + a fallback on an open one; an inclusive union one optional member per variant, each set when its variant admits the value ([unions](unions.md#a-value-several-variants-admit)) | [unions](../../ir/unions.md); INV2 |
| `LowerDiscriminator` | `Discriminator{Property/PropertyName/Index, Mapping→TypeID, Default, Envelope}` | a tag-dispatched decoder + typed factories + an encoder writing each variant's tag ([unions](unions.md#the-tag-a-variants-value-carries)) | [models](../../ir/models.md)–[unions](../../ir/unions.md) |
| `LowerOpenEnums` | `Enum.Closed`, `TypePlan.Open`, `ValueType`, `Members`, `Flags`, `FallbackMember`, `Ctx.Types` | the target's closed, open and flags forms, over the value type's row or its members' wire forms ([enums](enums.md#a-member-on-the-wire)); an open one keeps an unknown value, and one with no members takes its closed form ([enums](enums.md#an-enum-with-no-members)) | [enums](../../ir/enums.md) |
| `ExtractInterfaces` | `Implements`, `OperationGroup` | interfaces / client interfaces for testability | [models](../../ir/models.md) |
| `MapExternalTypes` | `External{Identity, Package, MinVersion}`, `Ctx.Types` | the type table's row for the identity ([type table](../contract/type-table.md)): imported library type + dependency-manifest entry; no row → opaque strategy + diagnostic | [containers](../../ir/containers.md) |
| `MaterializeValues` | `Value{Kind, Num BigVal, Ref, Ctor}` | literals; `Num` → bignum/decimal, never float64; `Ctor` → call; `symbol` → string explicitly; a default documented, never written onto a request ([values](values.md)) | [values](../../ir/values.md) |
| `BuildRequestShaping` | the binding the target lowers of `plan.BindingView` ([bindings](../plan/bindings.md)), `RequestContent`, the target's parameter shape ([request shaping](requests.md)), the service's `ShapeHint.ClientParams` ([client settings](../operations/client.md#client-settings)), `OpPlan.Auth` and the slot each scheme it names owns ([auth](../operations/auth.md#a-parameter-in-a-credentials-slot)), each operation's `Remount` and `AlsoMount` ([shaping hints](../contract/shaping-hints.md)) | request builders, per-protocol param binding, each operation's request type, an input `ParamBind.Text` marks its caller's string or pairs ([values as text](text.md#a-value-no-style-arranges)), with no input for a parameter in such a slot, and each method calling it, in its group after any `Remount` and in each group a `Mount` names, so `MarkDeprecation` finds them; for an operation the API sends, its request type alone | [bindings](../../ir/bindings.md) |
| `BuildOperationSettings` | each operation's `Ctx.Policy`, `OpPlan.Effects` and the statuses `Return`, `Others` and `Errors` declare | a row per operation of the runtime binding's settings table, in each unit holding a method that reads it ([output units](output-units.md#the-runtimes-unit)): its resolved policy, whether it retries an uncertain outcome, the statuses it declares, none of them followed as a redirect, and for an operation the API sends only the bound its body is read to ([runtime policy](../contract/runtime-policy.md#delivery)) | [operations](../../ir/operations.md); INV10 |
| `LowerHeaders` | `ResponsePlan.Headers` | a type with a field per declared header, each optional, read from the raw headers by wire name; a `WithResponse` method on a success ([return shapes](../operations/returns.md)), the failure value's and an `OtherResponse`'s `Headers` ([failures](../operations/errors.md), [return shapes](../operations/returns.md)) | [responses](../../ir/responses.md) |
| `LowerPagination` | `plan.PagePlan` (item unwrap, cursor paths, first page, stop rules) | an auto-pager sending [each next request](../operations/pagination.md#what-a-pager-sends-next) and ending where [the walk does](../operations/pagination.md#where-a-page-walk-ends); pacing left to policy | [interaction-patterns](../../ir/interaction-patterns.md) |
| `LowerStreaming` | `plan.StreamPlan` (direction; each side's content, framing, element, terminator and condition; an `Initial`, which is no frame over HTTP, under `protocol` alone) | a method per shape the operation offers, a stream a condition selects among them; a stream over an element of any kind; a `bytes` side lowered as a file; terminal and terminator ends | [interaction-patterns](../../ir/interaction-patterns.md) |
| `LowerLRO` | `plan.LROPlan` (final-state-via, poll/final ops, result path) | poller type + one poll and a poll until done, which returns the final type, paced and bounded by `Policy.Polling` | [interaction-patterns](../../ir/interaction-patterns.md) |
| `UnwrapEnvelopes` | `ResponsePlan.Envelope` | in the response decoder, the flag read before the body, a failing body the runtime's failure value decoded as the first of `Failures` its flag admits, and the member at `Value` returned in the body's place; the envelope whole in a `WithResponse` method's `EnvelopedResponse` ([envelopes](../plan/responses.md#envelopes), [return shapes](../operations/returns.md)) | [responses](../../ir/responses.md) |
| `LowerErrors` | `plan.PlannedError` | no error type: each entry's conditions, body decoder and declared facts in the operation's response decoder, which fills the runtime's failure value ([failures](../operations/errors.md)) | [responses](../../ir/responses.md) |
| `LowerOtherResponses` | `OpPlan.Others` | each entry's conditions in the operation's response decoder: `AsReturn` and a 2xx no entry answers read as `Return`, no body a nullable return or an ended pager or stream, any other a body decoder filling the runtime's `OtherResponse`, as a body that does not decode does ([return shapes](../operations/returns.md)) | [responses](../../ir/responses.md) |
| `BuildReceivers` | each operation's `HTTPBinding.Inbound`, its `OpPlan.Auth`, its request contents, and the responses `Return`, `Others` and `Errors` plan | no client method for an inbound operation, whose request type and settings row alone the steps from `BuildRequestShaping` to `LowerOtherResponses` give; a receiver per service holding a parse method for each, which refuses a scheme it was given no means to check and, unless a check or the unauthenticated setting is configured, an operation declaring none; and a type per declared response writing it, beside the request type ([operations the API sends](../operations/inbound.md)) | [http-binding](../../ir/http-binding.md#inbound-operations) |
| `LowerRedaction` | `TypePlan.Redacted`, a variant composed over a union a model narrows reading its `TypePlan.Composed` entry's, `TypePlan.Sensitive`, `Parameter.Secret`, a response's, an error case's or a part's `Header.Secret`, each `Document.Auth` scheme's `Kind`, `In`, `KeyName` and `Scheme` for the parameters in a credential's slot, its `Credentials`, and a header parameter's wire name where it is `Authorization` or `Proxy-Authorization` | `[REDACTED]` in every text rendering of a redacted value: the holder's string form, logging hooks, error messages; the wire untouched | [redaction](redaction.md); [properties](../../ir/properties.md) |
| `MarkDeprecation` | each entity's `Deprecation`, its `ReplacedBy` read through `EntityRef` | the target's deprecation mark on each declaration the entity lowers to, the shared sentence where it sets no field, its text in the documentation a caller reads where the mark shows no use, as for a positional parameter, each replacement a reference by ID the printer resolves after `ResolveCollisions`, a mechanical rewrite only where it compiles at every use ([deprecations](deprecation.md)) | [annotations](../../ir/annotations.md#replacements) |
| `MarkStability` | `OpPlan.Stability` | the tier in the operation's documentation, and an opt-in requirement where the target has one | [stability](../operations/stability.md); [operations](../../ir/operations.md#stability) |
| `PlaceDeclarations` | `Provenance.Source`, `TypePlan.Reach`, the target's placement options, each operation's `ShapeHint.Remount` and `AlsoMount` | the output unit each declaration lands in: the runtime's in a unit of its own, any other in one package unless a partition or a group split moves it ([output units](output-units.md)); on a target naming a file for its declarations' words, the file each lands in ([Go](../targets/go/naming.md#file-names)) | [provenance](../../ir/provenance.md) |
| `ComputeImports` | what each file's declarations reference: another unit's declarations, the runtime's among them, its own unit's and the language's default imports, and a type-table row's `Imports` | per-file import sets, each import by its path; the name a file gives it is settled with every other name, and one that keeps its own name where the language needs no import is printed as none ([reserved names](reserved-names.md)) | — |
| `RenderCasing` | neutral `Ident` (= `naming.Words`: the canonical words beside their source spellings; a name with none named by its characters) + the options' naming tables + the options version's letter case and the characters each role cannot hold as they stand | cased identifiers, the units' among them, each cased, composed and given its leading word and underscores before the target's form for a character its role cannot hold is written, the character's name on Go and backticks on Kotlin ([naming](naming.md#a-character-a-target-cannot-write-is-written-by-its-name)) — the ONLY place names get cased ([naming](naming.md)); one of a role a target writes into a path shortened past the options' length cap ([naming](naming.md#a-name-too-long-for-a-path-is-shortened)) | [naming](../../ir/naming.md); INV4 |
| `EscapeReservedWords` | cased `Ident` + each scope's reserved set: keywords, what the generated code binds there, on Go what its file imports, what a unit or a top-level declaration cannot be named ([reserved names](reserved-names.md)) | keyword-safe identifiers; NEVER touches `WireName`/`WireID` | [naming](../../ir/naming.md); INV4 |
| `ResolveCollisions` | `Ctx.Syms` (ID-keyed symbol table) | deterministic disambiguation in every scope, the units and each file's imports among them, an import yielding to what the target binds and, on Kotlin, to every declaration of its file, a nested one included, where on Go a parameter the spec names yields to it ([reserved names](reserved-names.md)), and a warning `emitters/naming/collision` for two names of different words told apart, rendered or folded alike ([naming](naming.md#collisions-and-the-names-a-generation-shipped)); never mutates IR identity | [identity](../../ir/identity.md); INV3 |

A step's Go forms are in [Go's step table](../targets/go/lowering.md#the-step-list-in-go).

Every `ir.TypeKind` has a dispatch here: `primitive` and `any` map through the type table ([type
table](../contract/type-table.md)) in `ResolveScalarChains`/type-reference lowering, `literal` in
`LowerLiterals`, the rest in the named steps above. The switch-completeness test ([mandatory
tests](../testing/mandatory-tests.md)) proves the coverage in the suite. A kind no compiler produces
yet dispatches to a coded degrade instead of a lowering ([what M3
lowers](../milestones.md#what-m3-lowers)), which keeps the coverage without a lowering nothing could
test. The concrete lowering strategies for the load-bearing axes are the documents beside this one.
