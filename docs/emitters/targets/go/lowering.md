# Go lowering table

Go's normative lowering of each construct of the [lowering table](../../refine/lowering-table.md).

| IR construct | Go |
|---|---|
| fixed-width `Primitive` (`int8`…`uint64`, `float32`, `float64`) | the same-named Go type, an integer read by value ([integers](types.md#integers)) |
| unbounded `Primitive` (`integer`, `number`, `float`) | `int64`, `float64` by the built-in type-table rows ([type table](../../contract/type-table.md)), marked `Inferred`; exact where a row maps them so: `*big.Int`, the runtime decimal |
| `decimal`, `decimal128` | the runtime decimal type, over `math/big` |
| `bool`, `string`, `bytes`, `url` | `bool`, `string`, `[]byte`, which json/v2 writes as base64, `string` |
| `uuid` | the standard library's `uuid.UUID` |
| `date`, `time`, `datetime`, `datetime_offset`, `duration` | runtime `Date`, `TimeOfDay`, `DateTime`; `time.Time`; a runtime ISO 8601 `Duration` |
| a primitive under an encoding with a row ([a row keyed by an encoding](../../contract/type-table.md#a-row-keyed-by-an-encoding)) | `base64`, `rfc3339` and `iso8601`: the primitive's own type; `base64url`: the runtime `Base64URL`, a `[]byte`; `http-date`: the runtime `HTTPDate`, over a `time.Time`; each of the two codes itself through `MarshalText` and `UnmarshalText` ([types](types.md#what-a-mapped-type-must-do)) |
| `any`, `Any` | `jsontext.Value`, which keeps the bytes, distinct from a diagnosed unknown |
| nil `*TypeRef` | void |
| `Scalar{Base}` chain | over the chain's root (`TypePlan.Scalar`), typed by the type table's row for the root and the chain's encoding ([type table](../../contract/type-table.md)): a defined type with a `Validate` for merged constraints where the root's type has no methods (a predeclared type, a slice, a map), an alias (`type X = Root`) over any other, its constraints checked where it is used ([declarations over a root](types.md#a-declaration-over-a-root)); nil base → newtype |
| `Model` (Base/Implements/Mixins) | struct with `Base` and `Mixins` flattened in; `Implements` → interfaces; a discriminated or `Abstract` base → a struct holding a sealed interface of its subtypes ([unions](unions.md)); `Positional` → index-ordered struct; a union along its composition, in `TypePlan.Unflattened`, lowered as [inheritance](../../refine/models.md#inheritance) lowers a model composing one |
| anonymous decorator: a `Model` with only a `Base`, or a `Scalar` with neither `Constraints` nor `Encoding`, beside annotations ([decorators](../../refine/decorators.md)) | no declaration: each reference lowered as one to the first type along its `Base` that is not a decorator, its docs, deprecation and examples folded onto the carrier |
| `Model` whose `Base` is no model, not a decorator | only an `allOf` that keeps composing, as with a `Base` that may be an object, a conjunct writing what only a `Model` holds or conjuncts no value satisfies, since any other over no object is no `Model` ([models](../../../ir/models.md#an-allof-no-object-satisfies)): a union base beside a property, mixin, required name, catch-all or discriminator of its own lowered as [inheritance](../../refine/models.md#inheritance) lowers a model composing one; any other base with no property, catch-all or discriminator of its own lowered as the `Scalar` row lowers an alias over that base, its constraints, docs and examples binding the position ([scalars](../../../ir/scalars.md)); anything else a diagnosed degrade |
| `AdditionalProps` / `Additional` | catch-all `map` as the embedded fallback; `closed`→`RejectUnknownMembers(true)`, pinned per model ([`User`](models.md#user-in-go)) |
| `Union` (four wire shapes, [unions](../../refine/unions.md#the-wire-shapes)) | a struct holding a sealed interface + marker + a wrapper per variant + a tag-dispatch (de)serializer on the struct; `Open` → an `Unknown` fallback; an inclusive `anyOf` → a struct with a pointer per variant ([unions](unions.md#an-inclusive-union)) |
| `Enum` open/closed/flags | a named type over the value type's row, consts named by enum then member (`StatusActive`, [enums](types.md#enums)): flags→bitset, an open one keeping a bit no member names; any other `TypePlan.Open`, every open one among them→consts+`Unknown`; any other→typed consts, strict decode, which refuses every value of an enum with no members, as its encoder does; `FallbackMember` on decode; a row with no Go constants → a named `string` over the wire text, its codec writing the value type's JSON kind, + a `Value()` of the row's type |
| `List`/`MapT`/`Tuple` | `[]T`/`map[K]V`/positional struct (optional past `MinItems`, `Rest`→trailing slice); `List.Encoding`→serializer mode |
| `Literal` | typed constant (incl. `symbol`) |
| `External` | the type-table row for its `Identity` ([type table](../../contract/type-table.md)): imported library type + dep-manifest; no row → opaque handle, passthrough + diagnostic |
| `Property.Secret`, `Parameter.Secret`, `TypeCommon.Sensitive` ([redaction](../../refine/redaction.md)) | `[REDACTED]` in the holder's `Format`, `String`, `GoString`, `Format` and `LogValue`, each on a value receiver and printing no deeper than the limit ([nesting](models.md#nesting)) ([`User`](models.md#user-in-go)), and a sensitive defined type's own ([declarations over a root](types.md#a-declaration-over-a-root)), in logging hooks and in error messages, a transport failure's `*url.Error` among them, which `net/http` writes with the URL it sent |
| `Operation.Stability`, `OperationGroup.Stability` ([stability](../../operations/stability.md)) | a doc-comment paragraph naming the tier and what it means ([stability](operations.md#stability)) |
| `Deprecation{Message, ReplacedBy}` ([deprecations](../../refine/deprecation.md)) | a last doc-comment paragraph opening `Deprecated:` and the shared text, never the bare marker, on each declaration and struct field the entity lowers to, which gopls v0.24.0 reports at each use in another package that selects it; a field keyed in a composite literal, which gopls does not report and staticcheck's `SA1019` does, named with its text in its struct's doc comment too, in a paragraph that does not open `Deprecated:`, which would mark the struct; a blank line in the text written as a line break, since gopls shows that paragraph alone; a positional path parameter's text in its method's doc comment; each replacement a doc link, `[Client.ListZonesV2]` within its package and `[example.com/sdk/orders.Client.GetOrderV2]`, by import path, from another, both of which `go/doc` parses as links; one with no declaration its name as text; no rewrite, since Go has no mechanism for one |
| `Visibility` sets | a struct per `ModelShape.Name`, an alias of the type's own where `ModelShape.Alias` is set, a union's with an alias for its interface and each wrapper and a function for each factory ([models](models.md#a-shape-that-is-an-alias)); a patch shape → optional ([TypePlan](../../plan/types.md#what-a-patch-relaxes)) |
| `Required` ⊥ `Nullable` ⊥ `Presence` | `T`/`Opt[T]`/`Nil[T]`/`OptNil[T]`/`omitzero`+presence; collapse→diagnostic; a reference on a cycle of references held by value `*T`, or `Opt[*T]` when optional and nullable ([recursive references](models.md#recursive-references)) |
| `Constraints` | field `validate` tags + refine-built `Validate()`; unrepresentable regex→diagnostic |
| `Discriminator{Mapping→ID}` | tag-dispatch `UnmarshalJSONFrom` on the union's struct, a tag carried as a number compared by value ([unions](../../refine/unions.md#discriminators)), + factories + a `MarshalJSONTo` writing each variant's tag ([unions](unions.md#discriminators)) |
| `Pagination` (PropPaths) | `iter.Seq2[T, error]` auto-pager; item unwrap from plan; pacing from policy |
| `Streaming` + `StreamDetail` | a method per shape offered; `Stream[T].Recv()`/`Send()` over an element of any kind, `string` where frames go unread; a `bytes` side as a file; terminal ends; no frame for an `Initial` over HTTP; direction from core, framing from plan |
| `LongRunning` | poller type + `Poll()`/`PollUntilDone()`; result from `ResultPath`; pacing from policy |
| `OneWay` | fire-and-forget method, no response binding |
| `HTTPBinding.Inbound` ([operations the API sends](../../operations/inbound.md)) | no client method; a `Receiver` beside the client, built from a `ReceiverConfig`, with a `Parse<Operation>(*http.Request)` method each, the config's `Verify` handed the whole request and what it stands in for and its `Unauthenticated` admitting an operation declaring no security, its request type in the `read` projection, and a type per declared response with `WriteTo(http.ResponseWriter)` ([operations](operations.md#operations-the-api-sends)) |
| `Channel`/`Message`/`MessageBinding` | the plan's `Message` binding → channel client + send/receive + reply routing (messaging target) |
| `ErrorCase{Fault, Retryable}` | one runtime `*APIError` holding the status, fault, kind, raw body and typed `Body` and `Headers`; `errors.Is` by fault and kind, `runtime.Body[T]` for the body ([failures](errors.md)); declared facts win over policy |
| `Response` beside the primary (`OpPlan.Others`) | one read as `Return` returned as the primary; no body → a nullable return, or a pager or stream that ends; another body, or a body that does not decode → `*OtherResponse` on the `error` path, with no fault and no retry; a 2xx the document does not list read as `Return` ([return shapes](returns.md)) |
| `Auth` OR-of-ANDs | `Authenticator` + per-scheme options; priority order; a scheme of kind `unresolved` takes the caller's `Authenticator`, and unconfigured with no other option is the `error` return naming the scheme, nothing sent ([auth](../../operations/auth.md#unresolved-schemes)); a parameter in the slot of a scheme the operation's options name is no field of `<Operation>Params` ([auth](../../operations/auth.md#a-parameter-in-a-credentials-slot)) |
| `Value{Num BigVal, Ctor, Ref, symbol}` | literals via decimal (never float64); `Ctor`→call; `symbol`→string explicitly; a `Default` documented, never written onto a request ([values](../../refine/values.md)) |
| `Naming{Canonical}` | cased via `naming.Policy`; a name with no words named by its characters, a mark, or in a package any character past ASCII, written by its name once the identifier is cased, one that would begin with a digit or a mark, or in an exported role with no upper-case letter, led by its role's word, and a break letter case cannot mark written `_` ([naming](../../refine/naming.md)); a package name folded, its characters past ASCII written `u` and their hex code point, and shortened past the length cap ([package directories](naming.md#package-directories)); a declaration's file named from its words ([file names](naming.md#file-names)); a name a scope reserves escaped with a trailing underscore, a parameter named as an import of its file and a unit named for a predeclared identifier among them ([reserved names](../../refine/reserved-names.md)); an import named as what the generated code binds or a predeclared identifier its file writes taking a name of its own ([imports](naming.md#imports)); collisions ID-keyed, and reported where the words differ |

## The step list in Go

What each step of the [canonical list](../../refine/steps.md) that states its result neutrally
lowers to in Go.

| Step | Lowers to |
|---|---|
| `ResolveScalarChains` | a defined type over a root with no methods, an alias over any other ([declarations over a root](types.md#a-declaration-over-a-root)), the root typed by the type table ([type table](../../contract/type-table.md)), + merged constraints; nil-base → newtype (opaque-scalar strategy) |
| `LowerContainers` | `[]T` / `map[K]V` / positional struct, its positions past `MinItems` optional and a `Rest` as a trailing slice; a nil `MapT.Key` is `string`, and any other key with a text is `map[K]V` whose names are read and written as that text ([types](types.md#integers)), one with none a diagnostic |
| `LowerLiterals` | typed constant / single-value newtype (incl. `symbol`) |
| `LowerModels` | struct over the flattened properties, an `Undeclared` member a required field typed as the catch-all types it, catch-all map as the embedded fallback, unknown members rejected on `closed` ([`User`](models.md#user-in-go)), members decoded under the runtime's integer readers ([integers](types.md#integers)), a union the model narrows lowered as that union ([inheritance](../../refine/models.md#inheritance)) and any other `Unflattened` conjunct lowered or degraded with a code |
| `ProjectVisibilityShapes` | `User` / `UserCreate` / `UserUpdatePatch` structs, one per `ModelShape.Name`, and `type UserCreate = User` where `ModelShape.Alias` is set, with `PaymentCreateVariant`, `PaymentCreateCard` and `NewPaymentCreateCard` beside a union's |
| `LowerOptionality` | the four+ states → `T` / `*T` / `Opt[T]`/`Nil[T]`/`OptNil[T]` / `omitzero` + presence bit; a reference on a cycle the target holds by value held through a pointer ([recursive references](models.md#recursive-references)) |
| `LowerConstraints` | field-level `validate` tags + a refine-built `Validate()` method structure |
| `LowerUnions` | a struct holding a sealed interface + marker method + a wrapper per variant or subtype + a fallback on an open one; on an inclusive union, a struct with a pointer per variant |
| `LowerDiscriminator` | tag-dispatched `UnmarshalJSONFrom` on the union's struct + typed factories + a `MarshalJSONTo` writing each variant's tag |
| `LowerOpenEnums` | closed → typed consts; open → consts+`Unknown(raw)`; flags → bitset; each over the value type's row, or the wire text where it has no constants; no members → the closed form, its decoder and its encoder refusing every value |
| `ExtractInterfaces` | Go interfaces / client interfaces for testability |
| `LowerPagination` | auto-pager yielding `iter.Seq2[T, error]`, sending [each next request](../../operations/pagination.md#what-a-pager-sends-next) from `PagePlan`; pacing left to policy |
| `LowerStreaming` | a method per shape the operation offers; `Stream[T]` with `Recv()`/`Send()` over an element of any kind; a `bytes` side lowered as a file; terminal ends |
| `LowerLRO` | poller type + `Poll()/PollUntilDone()` returning the final type, paced and bounded by `Policy.Polling` |
| `PlaceDeclarations` | a package per unit, and each declaration in the file its words name, those whose file names come out alike sharing one ([file names](naming.md#file-names)) |
